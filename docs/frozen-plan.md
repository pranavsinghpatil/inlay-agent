# Frozen delivery plan

Inlay Agent is a local-first Pi extension and loopback proxy that measures and conservatively reduces supported tool-output/context overhead. The first release proves transparent routing and telemetry. ObservationPack and deterministic transformations precede evaluation; adaptive compaction, the hosted evidence reducer, and action fusion are separately validated later.

Non-negotiables: one pinned Pi/provider configuration, no public binding, no raw audit archive by default, temporary bounded artifact storage only when ObservationPack is enabled, fail open on uncertainty, per-task paired evaluation, and no universal savings claims.
